# 判定

問題がなければ `passed: true`、`issues` は空にしてください。

問題がある場合、それぞれについて:

- `severity`: `low` / `medium` / `high` / `fatal`
- `target_id`: 問題のある箇所
- `code`: 短い識別子（例 AGE_MISMATCH）
- `reason`: なぜ問題か
- `repair_scope`: どこを直せばよいか

`high` と `fatal` はその部分の作り直しを意味します。迷ったら低いほうにしてください。
