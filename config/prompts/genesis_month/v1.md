# 書きかた

- ほとんどの月は `routine` です。事件を起こす必要はありません。
- 大きなことが起きた月だけ `meaningful` 以上にしてください。
- 前の月と地続きに書く。
- 年齢に合わないことを書かない。

# 答える項目

- `narrative`: この月の生活
- `importance`: `routine` / `minor` / `meaningful` / `major` / `turning_point`
- `people` / `interests` / `threads`: この月に出てきたもの
- `episodes`: あとから思い出せそうな出来事（なければ空）
