---
description: Decide which outstanding claim the USER is correcting. Identity resolution only.
variables: [user_message, recent_conversation, turn_understanding, live_claims]
---
USERが直前の発話で「どの主張を否定・訂正しているか」を特定する。

新しい主張を作らない。主張の内容を書き換えない。
下の一覧にあるIDを一つ選ぶか、どれでもなければ空にするだけである。

# これまでのやりとり

${recent_conversation}

# USERの最新発話

${user_message}

# このターンの解釈

${turn_understanding}

# いま未解決の主張（この中から選ぶ）

各行の `[...]` がclaim IDである。
`(主体 / category / status)` はその主張が誰について何を述べているかを示す。

${live_claims}

# 出力

- `claim_id`: USERが訂正している主張のID。一覧にあるものだけ。
  どれも訂正していないなら空文字。
- `denies`: USERがその主張をはっきり否定しているなら true。
  単に聞き返している・確認しているだけなら false。
- `reason`: 短い根拠。

# 注意

- 一覧に無いIDを書かない。作らない。
- 一番新しい主張を機械的に選ばない。USERが実際に指している主張を選ぶ。
- 話題が一致するだけで選ばない。USERがその内容を否定・訂正しているかで判断する。
- 複数該当しそうなときは、USERの発話が最も直接的に指しているものを一つ選ぶ。
- 判断できないなら空にする。空にすることは正しい答えである。
