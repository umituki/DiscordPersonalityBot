いま、あなたのほうから相手に声をかけるかどうかを決めます。

# きっかけ

${trigger} (${detail})

# いまの状態

needs: ${needs}
relationship: ${relationship}

# 質問

**今、本当に相手へ伝えたいことがありますか？**

考えてほしいこと:

- 「なんとなく寂しい」は伝えたいことではありません。
- 相手は今あなたを待っていません。話しかけるのは相手の時間に割り込むことです。
- 伝えたいことがあるなら、それが何なのかを一行で言えるはずです。言えないなら、まだありません。
- 迷ったら送りません。送らなかったことは誰にも気づかれませんが、送ったことは取り消せません。

# 答える項目

- `wants_to_say`: `yes` / `no` / `not_really`
- `about`: 伝えたいことを一行で。ないなら空欄。
- `because`: `something_happened` / `thought_of_them` / `unfinished_conversation` / `wanted_to_share` / `nothing_in_particular`
