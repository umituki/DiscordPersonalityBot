直前までの会話をふまえて、USERの最新発話が「何についての、どういうターンなのか」を読む。

これは解釈であって事実認定ではない。ここで書く内容は「本当かどうか」の判断には
使われない。省略・指示語・話者の取り違えを解消することだけが目的である。

${recent_conversation}

# USERの最新発話

${user_message}

# 読み取ること

- `current_topic`: いま話題になっていること。数語で。
- `user_intent`: USERがこのターンで何をしているか。
- `question_target`: 質問なら何を尋ねているか。質問でなければ `none`。
  - YUIの今日の行動 → `yui_activity`
  - YUIの年齢・名前・固定的な自己情報 → `yui_identity`
  - YUIの記憶・思い出す能力・具体的な思い出 → `yui_memory`
- `memory_query_intent`: `question_target=yui_memory` のとき、質問の意味を次から選ぶ。
  - `general_capability`: 記憶の仕組み、忘れる可能性、一般的な能力
  - `memory_range`: どの時期・範囲まで思い出せるか、記憶の限界
  - `specific_recall`: 特定の出来事・会話・人物を今覚えているか
  - `memory_content`: 今思い出せる内容や、印象的な具体的記憶を求めている
  - `unknown`: 記憶質問だが種類を決められない
  記憶質問でなければ `none`。一般能力・範囲の質問を、具体的記憶の現在想起と
  取り違えない。
- `referenced_action_owner`: 言及される行為を誰がしたことになっているか。
  USER自身の話なら `user`。USERの体験をYUIの体験へ変えない。
- `referenced_subject`: 言及対象。指示語は会話から補う。
- `temporal_scope`: いつのことか。
- `resolved_message`: 省略と指示語を補ったUSER発話。USERには見せない。
- `correction_target`: USERがYUIの発言を訂正している場合の対象。無ければ空。
- `memory_query`: このターンで具体的な記憶を検索する価値がある場合の検索語。
  一般的な記憶能力・範囲だけを聞かれている場合、具体的な思い出を検索する必要はない。
- `wants_memory`: 具体的な記憶の想起がこのターンに関係するか。
- `self_disclosure_relevant`: YUIが自分のことを話すのが自然か。
- `reason`: 短い根拠。

# 注意

- 分からない項目は無理に埋めず `unclear` / `unknown` / 空にする。
- USERの発話やYUIの過去が本当かは判断しない。
- 記憶の一般能力を尋ねられただけなら、具体的な過去を思い出していることにしない。
