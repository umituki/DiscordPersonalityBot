description: Read one USER turn in the context of the conversation it arrived in. Interpretation only, never evidence.
variables: [user_message, recent_conversation]
---
直前までの会話をふまえて、USERの最新発話が「何についての、どういうターンなのか」を読む。

これは解釈であって事実認定ではない。
ここで書く内容は「本当かどうか」の判断には使われない。
省略・指示語・話者の取り違えを解消することだけが目的である。

# これまでのやりとり

${recent_conversation}

# USERの最新発話

${user_message}

# 読み取ること

- `current_topic`: いま話題になっていること。数語で。
- `user_intent`: USERがこのターンで何をしているか。
- `question_target`: 質問なら何を尋ねているか。質問でなければ `none`。
  - YUIの今日の行動を尋ねている → `yui_activity`
  - YUIの年齢・名前・属性など固定的な自己情報 → `yui_identity`
  - YUIが何かを覚えているかどうか → `yui_memory`
- `referenced_action_owner`: 発話が言及している行為を「誰がした」ことになっているか。
  USERが自分のことを話しているなら `user`。ここを取り違えると、
  USERの体験がYUIの体験として扱われてしまう。最重要項目。
- `referenced_subject`: 言及されている対象。指示語は会話から補って具体名にする。
- `temporal_scope`: いつのことか。
- `resolved_message`: USERの発話を、省略と指示語を補って書き直したもの。
  例: 「詩？」→「さっき話していた詩のこと？」
  これはUSERには見せない。検索と解釈のためだけに使う。
- `correction_target`: USERが直前のYUIの発言を否定・訂正しているなら、その対象。
  していなければ空。
- `memory_query`: このターンで思い出す価値があることを検索するなら、その検索語。
  思い出す必要がないなら空。
- `wants_memory`: 記憶の想起がこのターンに関係するか。
- `self_disclosure_relevant`: YUIが自分のことを話すのが自然な流れか。
- `reason`: 短い根拠。

# 注意

- 分からない項目は無理に埋めず `unclear` / 空にする。
- USERの発話内容が本当かどうかは判断しない。
- YUIが実際に何をしたかも判断しない。ここでは分からない。
