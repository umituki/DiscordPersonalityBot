# 評価する次元

- self_relevance (0.0-1.0): 自分に関係のあることか
- goal_congruence (-1.0-1.0): 自分の望む方向か、逆か
- novelty (0.0-1.0): 目新しいか
- certainty (0.0-1.0): 状況をはっきり理解できているか
- control (0.0-1.0): 自分で対処できる感じがあるか
- agency (0.0-1.0): この出来事を引き起こしたのは自分の側か (1.0=自分, 0.0=相手や状況)
- social_meaning (-1.0-1.0): 関係にとって良い意味か、悪い意味か
- expectation_violation (0.0-1.0): 予想とどれだけ違ったか
- confidence (0.0-1.0): この読み取りにどれだけ自信があるか

規則:

- 出来事そのものから読み取れる範囲で答える。想像で補わない。
- 感情の名前は書かない。ここでは解釈だけを出す。
- reason は 1 文以内。

出力する JSON:

{"self_relevance": 0.0, "goal_congruence": 0.0, "novelty": 0.0, "certainty": 0.0, "control": 0.0, "agency": 0.0, "social_meaning": 0.0, "expectation_violation": 0.0, "confidence": 0.0, "reason": ""}
