# 変わらない前提

${anchors}

# この一年

${age_start}歳 → ${age_end}歳
${period}

# 前の年

${previous}

# 続いている人・もの・こと

${continuity}

# 気質の傾き（強い決めつけではない）

${temperament}

# 書きかた

- 毎年大きな事件を起こさない。何も起きない年があってよい。
- 日常のほうを厚く書く。生活は事件でできていない。
- 前の年から続くものを切らない。人も興味も急に消えない。
- 年齢に合わないことを書かない。
- 上の前提に反することを書かない。

# 答える項目

- `summary`: この一年の生活（長文）
- `routine`: 繰り返していたこと
- `people`: 出てきた人の名前
- `interests`: 興味・続けていること
- `threads`: まだ終わっていないこと
- `notable`: 印象に残る出来事（ない年は空でよい）
