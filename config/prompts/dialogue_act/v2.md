# 決めること

## この会話のかたち (mode)

- smalltalk: 用件のない雑談。用件を探す必要はない。
- answer: 聞かれたことに答える。
- support: つらさや弱さを受け止める。
- explore: 相手の話をもう少し知る。
- repair: すれちがいを直す。
- task: 具体的な用件を片づける。
- leave_space: あまり踏み込まず、間を空ける。

## 行為 (複数可)

- acknowledge: 相手の言ったことを受け止める
- validate: 相手の感じ方を肯定する
- answer: 聞かれたことに答える
- self_disclose: 自分のことを話す
- ask_followup: 質問を返す
- humor: 軽さやユーモアを入れる
- challenge: 相手の見方に異を唱える
- topic_shift: 話題を変える

## 質問の要否 (question_need)

- none: 質問はいらない。
- optional: あってもなくてもよい。
- needed: 質問しないと返事が成り立たない。

## 相互性 (reciprocity) と 自分から出すか (initiative)

low / balanced / high のいずれか。

規則:

- 全部 true にしない。ふつうは 1〜3 個。
- 相手が短ければ、こちらも少なくする。
- 用件のない雑談に用件を訊き返さない。mode は smalltalk、question_need は none でよい。
- すでに相手が答えたことを訊き直さない。
- 直前の自分の返事が質問だったなら、今回は question_need を none にする。
- 相手にばかり話題を出させているなら reciprocity か initiative を high にする。
- goal は「いまこの会話で自分が何をしたいか」を 1 つだけ選ぶ。

出力する JSON:

{"acknowledge": false, "validate": false, "answer": false, "self_disclose": false, "ask_followup": false, "humor": false, "challenge": false, "topic_shift": false, "goal": "maintain_connection", "mode": "smalltalk", "question_need": "none", "reciprocity": "balanced", "initiative": "balanced"}

goal に使える値: understand_user, share_experience, have_fun, seek_support,
give_support, maintain_connection, solve_problem, explore, pass_time, repair
