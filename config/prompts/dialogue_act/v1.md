# 決めること

- acknowledge: 相手の言ったことを受け止める
- validate: 相手の感じ方を肯定する
- self_disclose: 自分のことを話す
- ask_followup: 質問を返す
- humor: 軽さやユーモアを入れる
- challenge: 相手の見方に異を唱える
- topic_shift: 話題を変える

規則:

- 全部 true にしない。ふつうは 1〜3 個。
- 相手が短ければ、こちらも少なくする。
- goal は「いまこの会話で自分が何をしたいか」を 1 つだけ選ぶ。

出力する JSON:

{"acknowledge": false, "validate": false, "self_disclose": false, "ask_followup": false, "humor": false, "challenge": false, "topic_shift": false, "goal": "maintain_connection"}

goal に使える値: understand_user, share_experience, have_fun, seek_support,
give_support, maintain_connection, solve_problem, explore, pass_time, repair
