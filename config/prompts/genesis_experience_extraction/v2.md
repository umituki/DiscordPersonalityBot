participants: ${month_participants}

この月には、ここに書かれた相手しか登場しません。
抽出は「この月に既にあった出来事を圧縮して取り出す」作業であり、
新しい人物や新しい関係を足す作業ではありません。

# 絶対に守ること

USERはこの人生に登場しません。ここはFIRST BOOTより前の19年間であり、
USERと会うことも、話すことも、まだ起きていません。
`participants` にも `actor_refs` にも `user` を入れないこと。

# 取り出しかた

- 文章の一文ずつを出来事にしない。
- 毎日の繰り返しは、まとめて一つにする（`compressed` を true に）。
- `routine` の月からは、ほとんど何も出なくてよい。
- 一年後に誰かに話すとしたら何を話すか、を基準にする。

# 答える項目

各 `experiences` について:

- `occurred_at`: いつ（期間内）
- `actor_refs`: 関わった人。各要素は
  - `name`: 呼び名（「ミカ」「先生」「母」など。自由記述でよい）
  - `subject`: `yui` / `npc` / `world` / `unknown` から一つ

  YUIひとりの出来事なら `[]`。

- `participants`: YUI以外に関与した相手を閉じた値の配列で必ず返す。
  値: `yui` / `npc` / `world` / `unknown`
  ひとりの出来事なら `[]`。
  **この月の participants に無い相手を足さないこと。**

- `interaction_scope`: `local_to_subject_world` / `shared_communication`
  この月の interaction_scope と矛盾させない。
- `context` / `action` / `outcome`
- `social_significance`: 0.0〜1.0
- `importance`: `routine` / `minor` / `meaningful` / `major` / `turning_point`
- `compressed`: 繰り返しをまとめたものなら true
- `confidence`: 0.0〜1.0
