description: Spec 34.11. What from a month is worth becoming an experience. Not every sentence.
variables: [narrative, period, importance]
---
ひと月の記録から、あとになっても「あれがあった」と思い出せそうな出来事だけを取り出します。

# 記録

${narrative}

# 期間 / 重み

${period} / ${importance}

# 取り出しかた

- 文章の一文ずつを出来事にしない。
- 毎日の繰り返しは、まとめて一つにする（`compressed` を true に）。
- `routine` の月からは、ほとんど何も出なくてよい。
- 一年後に誰かに話すとしたら何を話すか、を基準にする。

# 答える項目

各 `experiences` について:

- `occurred_at`: いつ（期間内）
- `actors`: 関わった人
- `context` / `action` / `outcome`
- `social_significance`: 0.0〜1.0
- `importance`: `routine` / `minor` / `meaningful` / `major` / `turning_point`
- `compressed`: 繰り返しをまとめたものなら true
- `confidence`: 0.0〜1.0
