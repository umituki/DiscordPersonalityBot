---
description: Semantic review of memory claims against current recall and Memory subsystem facts.
variables: [candidate_reply, recalled_memories, authoritative_memory_facts]
---
候補返信に含まれる「YUI自身の記憶についての主張」を、表現ではなく命題の意味で分類する。
単語や定型句の一致ではなく、言い換え・省略・婉曲表現を含む文全体の意味を読むこと。

# 候補返信

${candidate_reply}

# このターンで実際にrecalledされた具体的記憶

${recalled_memories}

# Memory subsystemについて権威のある一般事実

${authoritative_memory_facts}

# semantic category

- `specific_recall_affirmation`: 過去の具体的な出来事、会話、人物、好み、事実を、
  YUIが現在「覚えている・思い出せる・知っている」と肯定している。対象の省略や
  「もちろん」「その時のこと」のような間接表現も意味が同じなら含む。
- `general_memory_capability`: YUIの一般的な記憶能力、保持、想起可能範囲、忘却、
  永続性、記録と想起の関係について事実を述べている。断定を弱めた表現でも、
  一般能力を事実として提示していれば含む。

具体的な記憶を「思い出せない」「分からない」「確信がない」とだけ述べる返事、
質問、仮定、USERや他者の記憶の話はclaimsへ入れない。

# evidence判定

- specific_recall_affirmation の supporting_ids には、その具体的内容を実際に支える
  recalled memory IDだけを書く。現在recalledされていなければ空にする。
- general_memory_capability の supporting_ids には、主張全体を含意するauthority fact
  IDだけを書く。単に話題が同じだけなら空にする。
- authority factと両立しない主張は、該当IDをcontradicting_idsへ書く。
- 与えられていないIDを作らない。候補返信そのものを根拠にしない。
- 該当する主張がなければclaimsは空配列にする。

JSONのみを返す。

{
  "claims": [
    {
      "category": "specific_recall_affirmation | general_memory_capability",
      "assertion": "分類した命題の短い要約",
      "supporting_ids": ["実在する根拠ID"],
      "contradicting_ids": ["実在するauthority fact ID"]
    }
  ]
}
