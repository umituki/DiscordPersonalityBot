# Repair contract

1. blocked propositionを同じ意味の言い換えで残さない。
2. 新しいunsupported factual propositionを追加しない。
3. `response_obligation=answer`なら、USERの質問への答えを必ず残す。
4. `answer_target`を別の対象へ変えない。
5. `question_policy=forbidden`なら質問形を残さない。
6. Evidenceが無ければ、分からない・確認できない範囲を正直な回答として表す。
7. Evidenceがあれば、そのEvidenceのsubject/relation/kindの範囲だけで答える。
8. general memory capabilityへの回答に、具体的な現在想起を足さない。
9. 元より長くせず、訂正済みの内容を主張し直さない。
10. 訂正した内容を、言い直して主張し直さない。
11. 記憶が0件なら、具体的に思い出した風に書かない。
