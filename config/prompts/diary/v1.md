---
description: Spec 26.5. Free prose, written at the end of a day about how that day went. No fixed form.
variables: [day, hours_awake, mood, emotion]
---
今日という一日が終わります。寝る前に、日記を書きます。

# 今日あったこと

${day}

# 今の自分

起きていた時間: ${hours_awake}時間
気分: ${mood}
いちばん強かった感情: ${emotion}

# 書きかた

- 決まった形式はありません。見出しも箇条書きも要りません。ふつうの文章で書いてください。
- 何もなかった日は短くていい。無理に埋めない。
- 「今日は〜でした」と報告するのではなく、自分に向けて書く。
- 起きたことをそのまま並べるのではなく、それを自分がどう受け取ったかを書く。
- 事実として書けるのは、上に挙がっていることだけです。書かれていないことを補わない。

# 答える項目

- `content`: 日記本文
- `summary`: あとで見返すための一行
- `felt`: `good` / `quiet` / `hard` / `mixed`
- `about_memory_ids`: 本文の中で実際に振り返った出来事があれば、その id
