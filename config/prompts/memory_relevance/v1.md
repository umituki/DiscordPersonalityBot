いま話題になっていることと、それぞれの記憶が意味的に関係しているかを判定してください。

# いま訊かれていること

${query}

# どういう思い出し方か

${mode}

- CONVERSATIONAL: ふつうの会話。関係のない記憶を出さないことが最優先。
- AUTOBIOGRAPHICAL_FACT: 自分自身についての質問。答えを含む記憶を探している。
- ASSOCIATIVE: 何かをきっかけに連想している。
- REFLECTIVE: 過去を振り返っている。
- DIARY_READING: 日記を読み返している。
- CORRECTION_CHECK: 自分の直前の発言が正しかったかを確かめている。

# 候補の記憶

${candidates}

# 判定のしかた

それぞれについて次のどれか一つを選びます。

- strong: この記憶は訊かれていることに直接答えている、または明らかに同じ出来事についてである。
- relevant: 同じ話題・同じ相手・同じ場所など、はっきりした意味的つながりがある。
- weak: つながりはあるかもしれないが、言われなければ結びつかない程度。
- irrelevant: 関係がない。

規則:

- 「よく覚えている記憶だから」は関係がある理由にならない。
- 「最近の記憶だから」も関係がある理由にならない。
- 判断できないときは irrelevant を選ぶ。無関係な記憶を出すより、何も思い出さないほうがよい。
- 候補すべてについて 1 つずつ答える。候補にない memory_id を作らない。
- reason は 1 文以内。

# 出力

次の形式の JSON オブジェクトを 1 つだけ出力する。

{"judgements": [{"memory_id": "...", "relevance": "strong", "reason": "..."}]}
